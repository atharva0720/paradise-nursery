# Paradise Nursery 🌿

A responsive React + Redux Toolkit shopping application for browsing and purchasing houseplants.

## Features

- Landing page with company information and background image
- Product listing with 9 plants in 3 categories
- Add to Cart functionality
- Disabled Add to Cart button after selection
- Dynamic cart item count
- Redux Toolkit cart state management
- Increase and decrease quantities
- Delete items
- Total quantity and total cost
- Checkout "Coming Soon" message
- Continue Shopping navigation
- Responsive design
- React Router navigation

## Technologies

- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Create a public GitHub repository named `paradise-nursery`.
2. Push this project to the repository.
3. Run:

```bash
npm install
npm run deploy
```

4. In GitHub, open **Settings → Pages** and select the `gh-pages` branch if required.

The application is configured with `/paradise-nursery/` as the Vite base path.
